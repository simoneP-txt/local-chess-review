# Opening names

`a.tsv` to `e.tsv` (columns `eco`, `name`, `pgn`) come unchanged from
<https://github.com/lichess-org/chess-openings>, branch `master`, commit
`3ba6b20d31b2e6125cb0e6a2e792f400717d9d39` (2026-11-05). `openings.py` reads them.
